# XR & Unity Developer Portfolio

This is a dynamic, JSON-driven personal portfolio designed for Senior Unity & XR Developers.

## Features
- **Dynamic Content Loading:** All project details, skills, experience, and metadata are read directly from `projects.json`.
- **Media Gallery & Video Support:** Shows YouTube embeds alongside a picture gallery within project modals.
- **Dark/Light Mode:** Full theme toggle support with CSS variables.
- **Admin JSON Generator:** Includes `admin.html` to generate formatted JSON entries without manual coding errors.

## Quick Start
1. Clone or download this repository.
2. Edit `projects.json` to reflect your profile, projects, skills, and experience.
3. Open `index.html` via a local server (or publish directly on GitHub Pages).
